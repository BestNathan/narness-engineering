## Methodological result from Pilot 0

The initial task list exposed a benchmark validity problem: several proposed bug tasks were already correctly handled by the frozen code.

The protocol was therefore amended from:

```text
Task → Agent
```

to:

```text
Treatment Base
  → Controlled Task Fixture
  → prove the requested condition is broken/absent
  → Fresh Agent Session
  → Patch
  → Acceptance Evidence
```

This is now a hard requirement for formal data.
